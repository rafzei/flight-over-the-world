# Samoloty Airbus wykorzystywane w komercyjnych lotach pasażerskich

Zestawienie obejmuje rodziny i główne warianty samolotów Airbusa, które weszły do komercyjnej eksploatacji pasażerskiej — zarówno używane obecnie, jak i historycznie. Uwzględnia loty regularne i czarterowe.

Data opracowania: **9 września 2026 r.**

## 1. Airbus A220

Dwusilnikowe samoloty wąskokadłubowe, wykorzystywane przede wszystkim na trasach krótkiego i średniego zasięgu. Rodzina powstała jako Bombardier CSeries, a następnie została włączona do oferty Airbusa.

| Model | Charakterystyka |
| --- | --- |
| **A220-100** | Krótszy wariant, wcześniej oznaczany jako Bombardier CS100. |
| **A220-300** | Wydłużony wariant o większej pojemności, wcześniej Bombardier CS300. |

## 2. Airbus A300

Dwusilnikowe samoloty szerokokadłubowe. Pierwsza rodzina samolotów pasażerskich Airbusa; produkcja została zakończona.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **A300B1** | Najwcześniejszy, krótszy wariant. Jeden z dwóch zbudowanych egzemplarzy był wykorzystywany komercyjnie przez Trans European Airways. |
| **A300B2** | Pierwszy wariant produkowany seryjnie, przeznaczony głównie na krótsze trasy. |
| **A300B4** | Wariant o większym zasięgu niż A300B2. |
| **A300-600** | Zmodernizowany wariant z kokpitem dla dwóch pilotów. |
| **A300-600R** | Odmiana A300-600 o zwiększonym zasięgu. |

## 3. Airbus A310

Dwusilnikowe samoloty szerokokadłubowe, krótsze od A300. Wykorzystywane m.in. na trasach międzykontynentalnych; produkcja została zakończona.

| Model | Charakterystyka |
| --- | --- |
| **A310-200** | Podstawowy, wcześniejszy wariant. |
| **A310-300** | Wariant o zwiększonym zasięgu. |

## 4. Rodzina Airbus A320

Dwusilnikowe samoloty wąskokadłubowe. Rodzina obejmuje modele **A318, A319, A320 i A321**. Wersje neo otrzymały nowsze silniki; starszą generację określa się zbiorczo jako ceo.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **A318-100** | Najkrótszy model rodziny. |
| **A319-100 / A319ceo** | Skrócony względem A320 model pierwszej generacji. |
| **A319neo** | A319 z silnikami nowszej generacji. |
| **A320-100** | Wczesny wariant A320, używany historycznie w lotach pasażerskich. |
| **A320-200 / A320ceo** | Główny seryjny wariant A320 pierwszej generacji. Określenie A320ceo obejmuje również starszy A320-100. |
| **A320neo** | Zmodernizowany A320 z silnikami nowszej generacji. |
| **A321-100** | Wczesny wariant wydłużonego modelu A321. |
| **A321-200** | Późniejszy wariant A321ceo o większym zasięgu i dopuszczalnej masie startowej. |
| **A321neo** | Wydłużony model rodziny z silnikami nowszej generacji. |
| **A321LR** | Odmiana A321neo o zwiększonym zasięgu, wykorzystywana m.in. na trasach transatlantyckich. |
| **A321XLR** | Odmiana A321neo o jeszcze większym zasięgu; w komercyjnej eksploatacji pasażerskiej od 2024 r. |

## 5. Airbus A330

Dwusilnikowe samoloty szerokokadłubowe, wykorzystywane na trasach regionalnych, średniego i dalekiego zasięgu.

| Model | Charakterystyka |
| --- | --- |
| **A330-200** | Krótszy wariant pierwszej generacji, o dużym zasięgu. |
| **A330-300** | Dłuższy wariant pierwszej generacji, o większej pojemności. |
| **A330-800** | Krótszy model rodziny A330neo. |
| **A330-900** | Dłuższy model rodziny A330neo. |

A330-200 i A330-300 określa się zbiorczo jako **A330ceo**, a A330-800 i A330-900 jako **A330neo**. Spotykane oznaczenia A330-800neo i A330-900neo odnoszą się do tych samych modeli.

## 6. Airbus A340

Czterosilnikowe samoloty szerokokadłubowe, projektowane do lotów dalekiego zasięgu. Produkcja została zakończona.

| Model | Charakterystyka |
| --- | --- |
| **A340-200** | Krótszy wariant pierwszej generacji. |
| **A340-300** | Dłuższy wariant pierwszej generacji. |
| **A340-500** | Wariant przeznaczony do tras o bardzo dużym zasięgu. |
| **A340-600** | Najdłuższy wariant rodziny, o największej pojemności pasażerskiej. |

## 7. Airbus A350

Dwusilnikowe samoloty szerokokadłubowe, wykorzystywane przede wszystkim na trasach dalekiego i bardzo dalekiego zasięgu.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **A350-900** | Podstawowy, krótszy model rodziny. |
| **A350-900ULR** | Odmiana A350-900 o bardzo dużym zasięgu, wykorzystywana m.in. przez Singapore Airlines. |
| **A350-1000** | Wydłużony model o większej pojemności pasażerskiej. |

## 8. Airbus A380

Czterosilnikowy samolot szerokokadłubowy z dwoma pełnymi pokładami pasażerskimi. Produkcja została zakończona, ale model pozostaje w eksploatacji pasażerskiej.

| Model | Charakterystyka |
| --- | --- |
| **A380-800** | Jedyny wariant A380, który wszedł do komercyjnej eksploatacji pasażerskiej; największy seryjny samolot pasażerski świata. |

## Jak czytać oznaczenia

- **ceo** — *Current Engine Option*, określenie generacji ze starszymi silnikami.
- **neo** — *New Engine Option*, generacja z nowszymi silnikami.
- **LR** — *Long Range*, zwiększony zasięg.
- **XLR** — *Extra Long Range*, jeszcze większy zasięg.
- **ULR** — *Ultra Long Range*, bardzo duży zasięg.

A321LR, A321XLR i A350-900ULR są odmianami modeli bazowych. Zestawienie pomija szczegółowe podtypy silnikowe, np. A320-214 i A320-232, oraz opcje wyposażenia. Wersje towarowe, wojskowe, biznesowe ACJ i projekty, które nie weszły do komercyjnej eksploatacji pasażerskiej, pozostają poza zakresem listy.
