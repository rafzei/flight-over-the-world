# Samoloty Boeing wykorzystywane w komercyjnych lotach pasażerskich

Zestawienie obejmuje rodziny i główne warianty samolotów Boeinga, które weszły do komercyjnej eksploatacji pasażerskiej — zarówno używane obecnie, jak i historycznie. Uwzględnia loty regularne i czarterowe.

Data opracowania: **9 września 2026 r.**

| Model lub rodzina | Charakterystyka |
| --- | --- |
| **Model 40 — warianty pasażersko-pocztowe, m.in. 40A i 40B** | Jednosilnikowe dwupłaty przewożące pocztę oraz niewielką liczbę pasażerów. |
| **Model 80 / 80A** | Trójsilnikowe dwupłaty pasażerskie z końca lat 20. XX wieku. |
| **Model 221 / 221A Monomail** | Pasażersko-pocztowe odmiany jednosilnikowego Monomaila, eksploatowane na amerykańskich trasach. |
| **247 / 247D** | Dwusilnikowe, całkowicie metalowe samoloty pasażerskie z chowanym podwoziem. |
| **307 Stratoliner** | Czterosilnikowy samolot z kabiną ciśnieniową, wykorzystywany w przewozach dalekiego zasięgu. |
| **314 / 314A Clipper** | Czterosilnikowe łodzie latające używane m.in. na trasach transoceanicznych. |

## Jak czytać listę

- **ER** — *Extended Range*, zwiększony zasięg.
- **LR** — *Long Range*, duży zasięg.
- **SP** — *Special Performance*, oznaczenie skróconego 747 o dużym zasięgu.
- **SR** — *Short Range*, wariant krótkiego zasięgu.
- **Combi** — jednoczesny przewóz pasażerów i ładunków na pokładzie głównym.

Lista obejmuje główne warianty, bez pełnego wykazu podtypów, kodów klientów i przebudów. Warianty konwertowalne, np. 727-100C, mieszczą się w odpowiednich rodzinach, jeśli były eksploatowane pasażersko. Kabiny VIP i oznaczenia BBJ nie są tu osobnymi rodzinami.

**737 MAX 7, 737 MAX 10 oraz 777-8 i 777-9 nie zostały zaliczone do modeli z potwierdzoną komercyjną eksploatacją pasażerską na dzień opracowania.** Certyfikacja, zamówienie lub lot próbny nie oznaczają rozpoczęcia przewozów pasażerskich.

Samoloty sprzedawane pod markami Douglas i McDonnell Douglas, np. DC-9, MD-80 i MD-11, stanowią osobne rodziny historyczne; samo przejęcie producenta przez Boeinga nie zmienia ich pierwotnej marki.
