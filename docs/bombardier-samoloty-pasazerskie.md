# Samoloty Bombardier wykorzystywane w komercyjnych lotach pasażerskich

Zestawienie obejmuje główne rodziny i warianty samolotów Bombardiera używane obecnie lub historycznie w przewozach pasażerskich. Obejmuje samoloty regionalne, a także odrzutowce wykorzystywane przez operatorów czarterów biznesowych i taksówek powietrznych.

Data opracowania: **9 września 2026 r.**

Bombardier rozwijał ofertę m.in. poprzez przejęcia Canadaira, de Havilland Canada, Learjeta i Short Brothers. Przy nazwach zachowano rozpoznawalne marki oraz zaznaczono pochodzenie poszczególnych rodzin.

## 1. Bombardier / de Havilland Canada Dash 8

Dwusilnikowe samoloty turbośmigłowe do przewozów regionalnych. Program powstał w de Havilland Canada, następnie był prowadzony przez Bombardiera, a w 2019 r. wrócił pod markę De Havilland Canada po sprzedaży programu.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **Dash 8-100 / DHC-8-100** | Najkrótszy wariant pierwszej generacji. |
| **Dash 8-200 / DHC-8-200** | Wariant zbliżony wielkością do serii 100, z mocniejszymi silnikami. |
| **Dash 8-300 / DHC-8-300** | Wydłużony wariant o większej liczbie miejsc. |
| **Dash 8-400 / Q400 / DHC-8-400** | Największy i najszybszy wariant rodziny, szeroko używany w przewozach regionalnych. |

Oznaczenia **Q100, Q200 i Q300** odnoszą się do odmian wyposażonych w system ograniczania hałasu i drgań. **Q400** i **Dash 8-400** oznaczają tę samą podstawową serię, a nie dwie osobne rodziny.

## 2. Bombardier / Canadair CRJ

Dwusilnikowe regionalne odrzutowce z silnikami w tylnej części kadłuba. Program CRJ został sprzedany Mitsubishi Heavy Industries w 2020 r.; samoloty pozostają rozpoznawane pod dotychczasowymi nazwami.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **CRJ100** | Pierwsza seryjna wersja regionalnego odrzutowca Canadaira. |
| **CRJ200** | Rozwinięcie CRJ100 z innym wariantem silników. |
| **CRJ440** | Odmiana CRJ200 z ograniczoną liczbą miejsc, dostosowana do wymagań części amerykańskich operatorów. |
| **CRJ700** | Wydłużony model kolejnej generacji. |
| **CRJ550** | Wariant oparty na CRJ700, z kabiną dla 50 pasażerów i większą ilością miejsca na bagaż oraz wyższe klasy podróży. |
| **CRJ705** | Odmiana oparta na CRJ900, z liczbą miejsc ograniczoną do 75. |
| **CRJ900** | Dłuższy wariant o większej pojemności niż CRJ700. |
| **CRJ1000** | Najdłuższy model rodziny CRJ. |

Oznaczenie **NextGen** dotyczy ulepszeń wybranych modeli CRJ, m.in. kabiny i wyposażenia. Wersje ER i LR mieszczą się w odpowiednich rodzinach.

## 3. Bombardier CSeries

Dwusilnikowe samoloty wąskokadłubowe, które weszły do eksploatacji jako Bombardier CSeries, a w 2018 r. otrzymały markę Airbus A220.

| Model Bombardiera | Późniejsza nazwa | Charakterystyka |
| --- | --- | --- |
| **CS100** | **Airbus A220-100** | Krótszy wariant rodziny. |
| **CS300** | **Airbus A220-300** | Wydłużony wariant o większej pojemności. |

CS100 i A220-100 oraz CS300 i A220-300 to odpowiednio te same konstrukcje. Przy łączeniu tej listy z [listą Airbusa](airbus-samoloty-pasazerskie.md) należy uniknąć podwójnego liczenia.

## 4. Short 330 i Short 360

Dwusilnikowe regionalne samoloty turbośmigłowe. Bombardier przejął Short Brothers w 1989 r., gdy produkcja tych rodzin jeszcze trwała. Samoloty zachowały markę **Short**.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **Short 330-100 / 330-200** | Regionalne samoloty pasażerskie z charakterystycznym prostokątnym przekrojem kadłuba. |
| **Short 360-100 / 360-200 / 360-300** | Wydłużona rodzina rozwinięta z Shorta 330, z pojedynczym statecznikiem pionowym. |

## 5. Bombardier Challenger

Dwusilnikowe odrzutowce biznesowe. W komercyjnych przewozach pasażerskich służą przede wszystkim do czarterów całego samolotu.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **Challenger 600** | Pierwszy model rodziny, opracowany przez Canadaira przed jego przejęciem przez Bombardiera. |
| **Challenger 601 — 1A, 3A, 3R** | Kolejne odmiany rozwojowe, używane m.in. w czarterach biznesowych. |
| **Challenger 604** | Rozwinięcie rodziny z większym zasięgiem i zmodernizowanymi systemami. |
| **Challenger 605** | Następca 604, z ulepszeniami kabiny i awioniki. |
| **Challenger 650** | Kolejna generacja dużej kabiny Challengera. |
| **Challenger 300** | Osobna konstrukcja klasy super-midsize, mniejsza od rodziny 600. |
| **Challenger 350** | Rozwinięcie Challengera 300. |
| **Challenger 3500** | Zmodernizowany następca 350, wykorzystywany przez operatorów czarterowych. |
| **Challenger 850** | Duży odrzutowiec biznesowy wywodzący się z CRJ200. |

## 6. Bombardier Global

Duże dwusilnikowe odrzutowce biznesowe dalekiego zasięgu, wykorzystywane m.in. w międzykontynentalnych czarterach pasażerskich.

| Model lub wariant | Charakterystyka |
| --- | --- |
| **Global Express** | Pierwszy model rodziny Global. |
| **Global Express XRS** | Rozwinięcie Global Express z ulepszonym zasięgiem i kabiną. |
| **Global 5000** | Krótszy model rodziny Global. |
| **Global 5500** | Zmodernizowany następca Global 5000. |
| **Global 6000** | Rozwinięcie linii Global Express XRS. |
| **Global 6500** | Zmodernizowany następca Global 6000. |
| **Global 7500** | Większy model z czterema strefami kabiny, używany m.in. przez VistaJet. |

**Global 8000** jest nowszą odmianą, której pierwsze dostawy rozpoczęły się w grudniu 2025 r. Potwierdzone dostawy do właścicieli prywatnych i firm nie są same w sobie dowodem wykonywania odpłatnych czarterów. W przejrzanych źródłach nie potwierdzono takiej eksploatacji, dlatego model pozostawiono poza główną tabelą komercyjnych przewozów.

## 7. Learjet — marka przejęta przez Bombardiera

Dwusilnikowe odrzutowce biznesowe, szeroko wykorzystywane w czarterach i taksówkach powietrznych. Bombardier przejął Learjeta w 1990 r.; wcześniejsze modele poniżej stanowią historię tej marki. Produkcję nowych Learjetów zakończono w 2022 r.

| Model lub rodzina | Charakterystyka |
| --- | --- |
| **Learjet 23** | Pierwszy seryjny Learjet, historycznie używany w przewozach biznesowych. |
| **Learjet 24 / 25** | Wczesne rodziny oraz ich odmiany, używane również komercyjnie. |
| **Learjet 28 / 29** | Rzadkie, późniejsze rozwinięcia wczesnej konstrukcji, z wingletami. |
| **Learjet 31 / 31A** | Lekkie odrzutowce biznesowe kolejnej generacji. |
| **Learjet 35 / 35A** | Popularne samoloty czarterowe z silnikami turbowentylatorowymi. |
| **Learjet 36 / 36A** | Odmiany o większym zasięgu, kosztem części miejsc pasażerskich. |
| **Learjet 40 / 40XR** | Krótsza rodzina wywodząca się z Learjeta 45. |
| **Learjet 45 / 45XR** | Rozwinięta rodzina lekkich odrzutowców biznesowych. |
| **Learjet 55 / 55B / 55C** | Rodzina z większym przekrojem kabiny. |
| **Learjet 60 / 60XR** | Rozwinięcie koncepcji Learjeta 55. |
| **Learjet 70** | Zmodernizowany następca Learjeta 40. |
| **Learjet 75 / 75 Liberty** | Zmodernizowana linia wywodząca się z Learjeta 45; Liberty to odmiana kabiny i oferty. |

## Jak czytać listę

Przewozy liniowe koncentrują się na rodzinach **Dash 8, CRJ, CSeries i Short**. **Challenger, Global i Learjet** należą do rynku lotów biznesowych, w tym odpłatnych czarterów. Prywatne używanie danego egzemplarza nie oznacza, że każdy lot tej rodziny jest komercyjny.

Lista pomija pełny wykaz podtypów silnikowych, wyposażenia, wersji specjalistycznych i towarowych. **Learjet 85** nie wszedł do eksploatacji. **DHC-6 Twin Otter i DHC-7 Dash 7** są konstrukcjami de Havilland Canada, których pierwotną produkcję zakończono przed przejęciem tej firmy przez Bombardiera; nie zostały tu nazwane samolotami produkowanymi przez Bombardiera.
