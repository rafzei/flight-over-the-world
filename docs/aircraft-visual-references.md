# E195LR, A321 and A320 visual references

Reference photographs downloaded and visually inspected on 10 September 2026. The shipped meshes are original, procedural, unbranded geometry; reference photos and airline liveries are not included as textures.

| Aircraft | Photograph / source page | Features used |
| --- | --- | --- |
| Embraer E195 | [Air Dolomiti E195, Olivati](https://commons.wikimedia.org/wiki/File:Air_Dolomiti_Embraer_195_Olivati-2.jpg) | Slender fuselage, small circular CF34 nacelles, four cockpit panes, conventional tail, swept winglets, one overwing exit per side. |
| Airbus A321 | [A321 myAustrian](https://commons.wikimedia.org/wiki/File:Airbus_A321_-_myAustrian_(1).jpg) | Stretched fuselage and four full-height door positions per side; same Airbus cockpit/nose proportions as A320. The game uses the sharklet option rather than this photograph's tip fences. |
| Airbus A320 | [A320-214 Airbus Industrie, JP7617615](https://commons.wikimedia.org/wiki/File:Airbus_A320-214,_Airbus_Industrie_JP7617615.jpg) | Fuller nose, framed cockpit panes, round intakes, two overwing exits per side and tall swept sharklets. |

Dimensions checked against the specification tables in [Embraer E-Jet family](https://en.wikipedia.org/wiki/Embraer_E-Jet_family) and [Airbus A320 family](https://en.wikipedia.org/wiki/Airbus_A320_family):

| Model | Length | Span |
| --- | ---: | ---: |
| E195 (first generation) | 38.66 m | 28.73 m |
| A321 with sharklets | 44.51 m | 35.80 m |
| A320 with sharklets | 37.57 m | 35.80 m |

Geometry remains a simplified flight-game representation, including approximate fuselage sections, engine profiles and landing gear. A321neo/LR/XLR and A320neo metadata share their respective basic silhouette. E195-E2/E295 is excluded because its wing and engines differ substantially. All four airliners, including the existing 737, share the same six-material instancing pipeline for player, menu, multiplayer and traffic.
